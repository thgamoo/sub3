# 재앙카드 투명 프레임 프롬프트

## 규격

- 카드 크기: 63mm × 88mm
- 기존 운명카드와 동일한 제목·일러스트·설명 영역 구조
- 카드 바깥, 제목 내부, 일러스트 영역, 설명 영역은 투명
- 설명 영역은 카드 전체 높이의 약 40%
- 중앙 분할선에 정면 해골 아이콘
- 프레임 색상은 짙은 적갈색, 검붉은색, 번트 엄버, 산화 구리

```text
Use case: background-extraction
Asset type: isolated transparent-ready Disaster Card frame

Create one front-facing standard 63 × 88 mm Disaster Card frame only on a perfectly flat solid #00ff00 chroma-key background.

Preserve a small empty title plaque, large upper illustration opening, horizontal divider, and a large lower description opening occupying approximately 40% of the card height.

Use a dark oxblood, burnt umber, red-brown, dried-blood burgundy, blackened iron, and aged-copper palette. Add restrained cracked-earth fissures, angular thorn-like filigree, ember-shaped corner marks, and subtle distressed metal texture.

Place one elegant frontal human skull icon, without crossbones, inside a circular medallion centered on the divider. No gore and no cartoon styling.

The surrounding background, title interior, illustration opening, and description opening must all be the same uniform #00ff00 for transparency removal. The only opaque object is the frame, divider, ornament, and skull medallion.

No text, letters, numbers, logo, watermark, book icon, crown, heart, rose, wax seal, crossbones, gore, paper panels, shadow, perspective, or second card.
```
