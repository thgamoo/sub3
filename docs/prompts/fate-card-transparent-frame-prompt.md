# 운명카드 투명 프레임 프롬프트

## 마스터 규격

- 카드 크기: 63mm × 88mm
- 검은색 프레임을 기준 마스터로 제작
- 카드 바깥, 제목 내부, 일러스트 영역, 설명 텍스트 영역은 투명
- 설명 영역은 카드 전체 높이의 약 40%
- 일러스트와 설명의 경계 중앙에 닫힌 책 아이콘
- 검은 마스터의 동일한 디자인과 알파 영역을 유지한 채 회색·흰색 파생본 제작

```text
Use case: background-extraction
Asset type: isolated transparent-ready board-game Fate Card frame master

Create one single front-facing standard 63 × 88 mm card frame only on a perfectly flat solid #00ff00 chroma-key background.

The opaque object consists only of the black Fate Card border, empty title-plaque outline, illustration/description divider, restrained silver ornament, and a closed-book medallion. The surrounding area, title interior, large illustration opening, and large description opening must all use the same uniform #00ff00 so they become transparent after chroma removal.

Use an elegant matte-black and deep-charcoal frame with restrained cold-silver engraved linework, thread-of-fate curves, tiny corner stars, and one small closed-book icon centered on the divider. No royal heraldry, crown, rose, heart, wax seal, gold, or colored accent.

The illustration opening occupies the upper area. The description opening starts near the three-fifths point and occupies approximately the lower 40% of the full card height. Both openings must remain completely empty.

Flat orthographic 2D production asset, exact 63:88 proportions, narrow print-safe frame, crisp edges, no perspective, no shadow, no paper backing, no texture inside the chroma areas, no text, no logo, no watermark.
```
