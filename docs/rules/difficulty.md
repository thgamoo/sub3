# 인원과 난이도 (Difficulty)

## 1. 플레이 인원

- **최대 4인** 게임이다.
- 플레이어블 캐릭터는 8종이지만, **동시에 플레이되는 것은 최대 4명**이다. (캐릭터 수 8 ≠ 플레이 인원 4)
- 선택되지 않은 나머지 플레이어블 캐릭터는 **시작 지점에 위치가 고정된 NPC**로 존재하며, 운명 카드의 지시로만 이동·행동한다. (NPC 운용은 [phases.md](phases.md) 참고)

## 2. 시나리오 덱 (난이도 무관 고정)

- 시나리오 덱은 **모든 난이도에서 동일**하다. 초반부 16장 + 중반부 16장 + 후반부 16장 = **운명 카드 48장**, 막당 2장씩 **24막**에 소진된다. ([phases.md](phases.md) 참고)
- 즉 어떤 난이도로 하든 세 구간의 서사가 전부 전개된다. **난이도는 덱이 아니라 두근! 토큰 개수로만 조절**한다.

## 3. 난이도별 두근! 토큰

난이도는 5단계이며 꽃 이름을 따른다. 오름차순(쉬움 → 어려움). 두 축으로 조절한다.

- **플레이어 시작 두근!** — 낮을수록 내가 죽기 쉽다(어려움).
- **NPC 서브빌런 시작 두근!** — 높을수록 NPC가 잘 죽지 않아 처치·정리가 어렵다(어려움). ([tokens.md](tokens.md#9-두근-토큰) 참고. 미선택 플레이어블 캐릭터 = NPC 서브빌런)

| 난이도 | 플레이어 시작 두근! | NPC 서브빌런 시작 두근! |
| --- | --- | --- |
| 데이지 (Daisy) | 5 | 0 |
| 릴리 (Lily) | 5 | 1 |
| 로즈 (Rose) | 3 | 1 |
| 아네모네 (Anemone) | 2 | 1 |
| 리코리스 (Lycoris) | **1** | **2** |

- 쉬운 쪽(데이지)일수록 내 두근!이 넉넉하고 NPC는 두근!이 없어 손쉽게 정리된다.
- 어려운 쪽(리코리스)일수록 내 두근!은 1개뿐이고 NPC 서브빌런은 두근! 2개를 깔고 시작해 오래 버틴다.
- 두근!은 회복 불가 자원이며 NPC도 동일하게 취급한다(0이 되면 사망 → `악령`). ([tokens.md](tokens.md#9-두근-토큰) 참고)

> 셋업 절차는 [setup.md](setup.md) 참고.
