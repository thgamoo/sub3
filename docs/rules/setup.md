# 셋업 절차 (Setup)

1. **시나리오 덱 구성** — 선택한 난이도의 배분([difficulty.md](difficulty.md))에 맞춰 운명 카드로 초반부/중반부/후반부 덱을 구성한다. 각 구간 덱의 **맨 위에 해당 구간의 시나리오 카드를 1장씩** 올린다.
2. **탐색 덱 구성** — [tokens.md](tokens.md)의 "지역별 탐색 덱" 절차에 따라 동·서·남·북에 20장씩 배치한다. (각 덱 = 물건 10 + 금화 10)
3. **캐릭터 배정** — 플레이어는 랜덤으로 캐릭터를 배정받는다. 선택되지 않은 캐릭터는 시작 지점에 NPC로 배치한다.
4. **선 플레이어 결정** — 전원 주사위를 굴려 가장 낮은 눈이 선. 동점자는 재굴림. 진행 방향은 선이 정한다. (상세는 [phases.md](phases.md) 참고)
5. **초기 자원 배분** — 난이도·캐릭터·순번에 따라 자원을 배분한다.
   - 난이도 리코리스: 두근! 토큰 1개로 시작 (그 외 난이도는 3개)
   - 순번 3위·4위 플레이어: **빌런 포인트 1점** 또는 **능력 카드 1장 추가** 중 선택
6. **이상형 카드 세팅** — 각 남주에게 이상형 카드를 랜덤으로 **3장씩 뒷면으로** 배치한다.
7. **시나리오 개시** — 초반부 시나리오 카드를 낭독하고 게임을 시작한다.
