## 3. 물건 카드 (뒷면 파랑)

문서 전체에서 물건 카드는 다음 계층으로 통일한다.

```
물건 카드 (뒷면 파랑)
├── 단서   — 캐릭터 과거의 단서 27장
├── 유물   — 세계 진실 물건 10장 + 엘릭서 3장 = 13장
└── 금화   — 40장 (탐색 덱 분배분. 총 금화는 §5 참고)
```

- 단서 + 유물 = 좁은 의미의 "물건" 40장.
- 여기에 금화 40장을 더한 **총 80장이 4개의 지역 탐색 덱**을 이룬다. (아래 §3.4 참고)

### 3.3 지역별 탐색 덱 (4개)

> 물건 카드 더미는 하나가 아니라 **4개**다.

- **동·서·남·북 각 지역마다 독립된 탐색 덱**이 존재하며, 각 덱은 **20장**이다.
- 총 80장 = 물건(단서+유물) 40장 + 금화 40장.

**셋업 시 분배 절차**

1. 물건(단서+유물) 40장을 잘 섞은 뒤 **10장씩 4묶음**으로 나눈다.
2. 각 묶음에 **금화 10장씩**을 넣는다.
3. 각 묶음을 다시 섞어 동·서·남·북 지역에 1덱씩 배치한다. (각 20장 = 물건 10 + 금화 10)

**확률과 리셔플**

- 각 지역 덱의 초기 물건/금화 비율은 정확히 1:1이다.
- **리셔플은 하지 않는다.** 탐색을 반복할수록 해당 지역의 물건/금화 비율이 틀어지는 것은 **의도된 설계**다. 어느 지역에서 탐색을 반복할지가 전략적 선택이 된다.

**탐색 덱 고갈 처리**

- 어떤 지역의 탐색 덱이 **고갈되는 즉시, 세계은행연합의 금화를 2장 해당 지역에 보충**한다.
- 카드 2장을 뽑아야 하는데 1장만 남은 경우: 그 1장을 가져가는 즉시 고갈이 발동하므로, **금화 2장을 보충한 뒤 나머지 1장을 그 금화에서 뽑는다.**
- **설계 귀결**: 고갈 이후에는 금화만 보충되므로 `단서`와 `유물`은 게임 전체에서 유한하다. 한 번 소진되면 다시 나오지 않는다. 진실 규명·과거 청산 엔딩을 노린다면 초반의 탐색 배분이 결정적이다.

### 3.4 지역별 탐색 가능 여부

| 지역 | 탐색 | 사용하는 덱 |
| --- | --- | --- |
| A 동부 | 가능 | 동부 덱 |
| B 서부 | 가능 | 서부 덱 |
| C 남부 | 가능 | 남부 덱 |
| D 북부 | 가능 | 북부 덱 |

| F 동부 바다 | 가능 | **동부 덱** (동부로 간주) |
| G 극동의 섬 | **불가** | — |

## 4. 재앙 카드

> **10종 각 1장, 총 10장. 뒷면: 검은색.** 상세 내용은 [omens.md](../omens.md) 참고.

- 섞었을 때 [운명 카드](#5-운명-카드)와 구분되지 않아야 하므로, **뒷면 디자인이 운명 카드와 완전히 동일**해야 한다.
- 셋업 시 덱에 미리 넣지 않는다. 게임 중 **악령의 `징조`**로 유입되며, 악령은 재앙 카드의 내용을 확인하지 못한 채 그 시점 진행 중인 구간(초반/중반/후반) 운명 카드 더미에 섞어 넣는다.

### 4.1 재앙 관련 토큰·마커

> v1 밸런싱([omens.md](../omens.md))의 지속 효과를 보드에 표시하기 위한 구성품. **수량은 밸런싱 확정 후 조정.** (재앙 카드는 10종 각 1장 → 동시에 한 종류만 발동)

| 구성품 | 용도 | 수량(초안) |
| --- | --- | --- |
| 선혈의 비 토큰 | 선혈의 비(1): 주사위로 정한 지역에 놓고 **게임 종료까지** 유지 | 1 |
| 전염병 토큰 | 돌림병(3): 감염 지역 표시, 막 종료마다 이웃 지역으로 확산(동부 바다·극동 제외) | 5 |
| 파리 떼 토큰 | 파리(8): 막 종료 시 마지막 플레이어의 주사위 눈에 따라 이동(1~5=지역, 6=제자리), **게임 종료까지** 유지 | 1 |
| 범용 재앙 마커 | 마수폭주(7) 지정 지역, 소멸(9) 사라진 지역, 흑암(4) 활성(전역이라 보드 중앙 1개) 표시 겸용 | 2 |

- 마수폭주(7)는 **국지형**으로 지정 지역을 범용 재앙 마커로 표시한다. 파리(8)는 **이동형**으로 파리 떼 토큰이 매 막 주사위(1~5=지역, 6=제자리)에 따라 옮겨 다닌다. 선혈의 비(1)·파리(8)는 **게임 종료까지 지속**된다.
- 즉발형 재앙(칼날 비2·마력폭발5·초태 몰살6·종막10)은 지속 구성품이 필요 없다.
- **막(라운드) 트래커**: 재앙의 지속 막 수(3막)와 흑암의 해제 시점, 전체 24막을 세기 위해 **보드에 24칸 막 트랙 + 마커 1개**가 필요하다. (재앙 전용이 아니라 게임 공통 구성품 — 현재 문서에 미반영)

## 9. 두근! 토큰

- **정의**: 사랑·연민·상냥함 등 **인간성의 집합 구현체**. 게임적으로는 라이프에 해당한다.
- 분홍색 하트 + 동그라미 형태의 토큰.
- **빙의된 플레이어 캐릭터**와 **NPC 서브빌런**(미선택 플레이어블 캐릭터) 모두 지급받는다. 남주·메인 악녀·주인공(잔느)은 갖지 않는다.
- **시작 개수는 난이도로 결정된다.** 수치의 단일 출처는 [difficulty.md](difficulty.md#3-난이도별-두근-토큰)이다. (플레이어 5~1개 / NPC 서브빌런 0~2개)
- **회복 수단은 존재하지 않는다.** 소모되기만 하는 일방향 자원이다.
- 모두 잃으면 **인간으로서 사망**하고 `악령`이 된다.
- `빈사` 상태 판정은 두근! 토큰과 **별개**의 시스템이다.
- "두근! 토큰"과 "두근! 포인트"는 같은 자원을 가리킨다.

## 10. 빌런 토큰 (= 빌런 포인트)

- 빨간색·검은색 바탕 + 악녀 실루엣 + 동그라미 형태의 토큰.
- **빌런 토큰과 빌런 포인트는 동일한 것이다.** 문서 전체에서 용어를 하나로 취급한다.
- 획득: **암살에 성공할 때마다 1개.** (악령의 `살인귀`·`징조`도 각 1개)
- 용도 1 — **운명 저항력**: 빌런 포인트 1개당 운명 카드 1장의 강제력을 회피할 수 있다.
- 용도 2 — **승점**: 멸망 엔딩 시 최다 보유자가 승리하며, 동시 달성 시 1순위 타이브레이커로도 쓰인다. ([phases.md](phases.md)의 "동시 달성 시 승자 판정" 참고)

## 12. 금화

- **총 60장.**
- 배치: **40장은 4개의 탐색 덱에 10장씩 분산**(§3.3), **20장은 세계은행연합**이 보유한다.
- 플레이어가 이동·거래 등으로 지불한 금화는 **세계은행연합으로 귀속**된다.
- 운명 카드 효과로 지급되는 금화는 세계은행연합의 보유분에서 충당한다.
- 신규 발행 금화는 **금화 요정**이 관리한다. (설정 상세는 별도 문서 예정)
- 거래 규칙은 [actions.md](actions.md)의 "거래" 참고.

### 금화 순환 구조

```
세계은행연합 (초기 20장 + 유입분)
   │  덱 고갈 시 2장씩 보충
   ▼
지역 탐색 덱  ──탐색──▶  플레이어
   ▲                        │
   │                        │ 이동 비용 1장
   │                        │ 거래 수수료 2장 (암상)
   │                        │ 거래 파괴 의뢰 3장 (암상)
   └────────────────────────┘
        암상이 받은 금화도 세계은행연합으로 귀속
```

- 이 순환 때문에 **후반부에 금화가 말라 이동이 완전히 봉쇄되는 상황은 발생하지 않는다.** 지불한 금화는 세계은행연합에 축적되고, 덱 고갈을 통해 다시 시장에 풀린다.
- 다만 순환에는 시차가 있으므로, 이동을 신중하게 만드는 압박 자체는 유지된다.

- **6면체 주사위 1개.** 모든 판정은 이 주사위 하나로 처리한다.
- 사용처: 탐색 판정 / 모략 판정 / 선 플레이어 결정 / 현상수배 턴 시작 판정 / 악령의 사고기원.

## 15. 설명서 · 요약 카드

### 15.1 설명서 (룰북)

> **1부.** 게임 전체 규칙을 담은 책자.

- 셋업, 막·턴 진행, 각 행동의 상세 규칙, 재앙·운명 시나리오, 엔딩 판정 등 전 규칙을 수록한다.
- 실제 플레이 중에는 자주 펼치지 않아도 되도록, 자주 쓰는 정보는 아래 §15.2 요약 카드에 압축한다.

### 15.2 요약 카드 (플레이어 에이드)

> **양면인쇄. 수량: 인원수만큼.** 각 플레이어가 1장씩 손 닿는 곳에 둔다.

플레이 중 설명서를 펼치지 않고도 한 턴을 굴릴 수 있도록, **한 턴에 할 수 있는 행동 8종**을 **앞면 4개 · 뒷면 4개**로 나눠 담은 참조 카드. 상세 규칙은 [actions.md](actions.md)가 단일 출처이며, 이 카드는 그 요약이다.

**앞면 — 행동 1~4**

| 행동 | 요약 |
| --- | --- |
| 이동 | 이웃 지역으로 이동. 금화 1장 지불. |
| 탐색 | 주사위: 1·2 능력 1장 / 3·4·5 물건 1장 / 6 물건 2장(또는 능력 2 + 물건 1). |
| 수행 | 능력 카드 2장을 뽑는다. 아카데미(중부)에서는 3장. |
| 각성 | 같은 능력 카드 5장을 내고 고유 능력을 얻는다. |

**뒷면 — 행동 5~8**

| 행동 | 요약 |
| --- | --- |
| 만남 | 매력 카드 1장을 써서 남주 성향 카드 1장을 오픈한다. |
| 모략 | 같은 능력 카드 2~5장 사용, 주사위 판정. 초과=발각 / 미만=처단 / 동일=암살. |
| 거래 | 같은 지역 상대에게 금화 5개를 걸고 제안(수수료 2 + 상대 3). 거절·파괴 의뢰 가능. |
| 약혼 | 오픈된 성향 조건을 능력·물건으로 충족해 남주와 약혼한다. |

> 실제 배치·조판은 웹 데모 [demo/summary-card.html](../../demo/summary-card.html)에서 확인한다.
