# 멸망엔딩 - 내가 가질 수 없다면 부숴버릴거야.

## 충족 조건

- 모든 플레이어가 사망
- 빌런 포인트를 가장 많이 획득한 사람이 승리

## 멸망 시나리오의 시작과 멸망 엔딩의 충족 조건에 대하여.

- 1명의 플레이어가 사망하는 즉시, 그 플레이어 카드를 뒤집고 `악령` 상태가 된다.
- 악령 전환 시 보유 자산은 다음과 같이 처리한다.

| 보유 자산 | 처리 |
| --- | --- |
| 능력 카드 / 단서 / 유물 | 2장당 해골 카드 1장으로 치환 (홀수는 버림) |
| 금화 | 2장당 해골 카드 1장으로 치환 (홀수는 버림) |
| 두근! 토큰 | 남아 있다면 **빌런 토큰으로 치환** |
| 오픈된 이상형 카드 | 공유 자산이므로 처리하지 않는다 |
| 각성한 고유 능력 | **소멸한다** |

> 통상적으로는 두근! 토큰을 전부 잃어야 악령이 되지만, 그 외의 경로(운명·재앙 카드 등)로 사망하는 경우를 위해 두근! 토큰 치환 규칙을 둔다.
- 악령은 자기 차례에 액션 2번을 다음 중 선택하여 할 수 있다.
  - 이동: 다른 지역으로 이동
  - 저주: `해골` 카드 1개 사용. 같은 장소의 있는 플레이어를 지정. 그 플레이어가 가진 능력 카드를 무작위로 1장 버린다.
  - 사고기원: `해골` 카드 1개 사용. 주사위 굴려서 같은 장소에 있는 플레이어를 공격할 수 있음. 4이상의 눈금이 나왔을 시 **대상 플레이어가** `두근!` 토큰을 하나 잃는다.
  - 악성악화: `해골` 카드 1개 사용. 빌런의 뒤에 겹쳐서 둔다. 겹쳐 둔 개수에 따라 빌런 공격의 회피 눈금 제한이 올라간다. **1~2개: 3 / 3~5개: 4 / 6개: 5.**
  - 살인귀: 만약 빌런의 겹쳐진 `해골` 카드가 6장이었던 경우, 7장으로 추가하는 대신 해당 빌런을 사고사 처리한다. 해당 빌런을 죽인 악령은 빌런 포인트를 1 획득한다.
  - 절규: `해골` 카드 2장 획득
  - 징조: `해골` 카드 5장 사용하여 `재앙`카드를 `운명` 카드 더미에 놓고 섞는다. 빌런 포인트를 1 획득한다.
- 모든 플레이어가 사망하게되면 즉시 `멸망` 엔딩의 조건을 충족한다. 해당 라운드를 진행한 후 엔딩을 맞이한다.

## 악령의 지속과 승리 자격

- 악령은 **소멸하지 않으며 18막이 끝날 때까지 지속**된다.
- **멸망 엔딩에 도달한 경우**, 악령도 빌런 포인트(승점) 순위로 승패를 가린다. 사망 후에도 우승할 수 있다.
- **멸망 외의 엔딩으로 게임이 끝난 경우, 악령은 무조건 패배**한다.
