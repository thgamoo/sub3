# 군림엔딩 - 짐의 발 앞에 조아리거라.

## 충족 조건

1명이 다음의 조건을 모두 충족한다.

- 생존
- 능력을 각성한 상태
- **황제의 증표 획득** — 다음 중 하나로 취득한다:
  - 극동의 섬(G)에서 **과거 진실 단서 3장을 지불** (기본)
  - **메인 악녀** 상태로 남주와 약혼 (후반 서막, [scenario.md](../scenario.md))
  - 미호 "요술의 왕" (마법 카드 5장) / 그레이스 "만물금본" (금화 지불)
- 황제의 증표를 가진 플레이어가 여러 명이라면 황제 선언을 할 수 없다.
- 본 대륙으로 돌아와 황제선언 후 다음 라운드 되기 (1라운드 필요)

> **황제는 하나뿐** — 황제의 증표 보유자끼리 조우하면 무조건 [모략]으로 한 명이 죽을 때까지 싸운다(패자는 증표를 잃는다). ([scenario.md](../scenario.md)의 후반 "극동의 옥좌" 참고)
