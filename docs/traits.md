# 남주 성향 카드

> **초안 (v5)** — 내용 검토·수정용. 구성품 사양은 [rules/tokens.md](rules/tokens.md#7-남주-성향-카드) 참고.

## 용어

- **성향** — **남주 본인의 성격**. 카드 이름이 곧 그 남주가 어떤 사람인지를 말한다.
- **이상형** — 그런 성향의 남주가 **상대에게 바라는 조건**. 이걸 충족해야 마음을 얻는다.

예: 성향이 `금본주의자`인 남주는 값을 따지는 사람이므로, 그의 이상형은 `금화 3`이다.


## 구성

- **총 20장, 뒷면 분홍색.**
- 게임 시작 시 각 남주에게 **3장씩 뒷면으로 랜덤 배치** (4남주 × 3 = **12장 사용**).
- 나머지 8장은 게임에서 제외
- [만남](rules/actions.md) 행동으로 매력 카드 1장을 써서 1장씩 오픈한다.
- **약혼하려면 오픈된 성향 카드의 이상형을 전부 충족해야 한다.**
- **충족에 사용한 능력 카드·금화는 버린다.**

> **"미사용 8장"이란** — 20장 중 실제로 남주에게 깔리는 건 12장뿐이라,
> 나머지 8장은 그 판에 등장하지 않는다는 뜻이다.
> 매 판 남주의 성격이 달라지므로 반복 플레이에서 변화가 생긴다.

## 약혼 구조 — 잔느와의 줄다리기

- 약혼 **시도** 자체는 언제든 할 수 있으나, 오픈된 이상형을 전부 충족해야 성립한다.
- 운명 카드 등으로 **잔느가 역으로 유혹**하는 경우, 아직 약혼이 성립하지 않았다면
  **약혼 진행 주체가 잔느로 바뀌고 성향 카드가 1장 더 오픈**된다.
- **되찾을 수 있다.** 늘어난 이상형까지 전부 충족하면 다시 약혼해 주체를 가져온다.
- **단 3장이 모두 오픈된 상태에서 잔느가 가져가면 끝이다.** 더 열 카드가 없으므로 되찾을 수 없다.

| 뺏긴 시점 | 오픈 장수 | 결과 |
|---|---|---|
| 1장 오픈 상태 | → 2장 | 2장을 모두 충족하면 탈환 |
| 2장 오픈 상태 | → 3장 | 3장을 모두 충족하면 탈환 |
| **3장 오픈 상태** | — | **영구 상실** |

→ **빠르게 약혼할수록 안전하다.** 늦어질수록 요구 자원이 늘고, 기회 자체도 줄어든다.
이 압박은 구조가 이미 만들어주므로 **개별 이상형을 무겁게 잡을 필요가 없다.**

## 이상형의 기본 단위

이상형 하나는 기본적으로 다음 둘 중 하나다. 1장짜리는 너무 가벼워 쓰지 않는다.

- **같은 능력 카드 2장** — 한 가지를 확실히 요구하는 성향 (무투파·책벌레·독실·마조히즘 …)
- **서로 다른 능력 카드 3장** — 여러 방면을 보는 성향 (귀족주의·기사도·재능주의 …)

여기에 능력 카드가 아닌 축을 쓰는 것들이 따로 있다 —
금화(물질만능주의), 물건(수집가), 각성 상태(노력가), 빌런 포인트(상냥함), 두근! 토큰(진심을 준다면).

**남주의 성격에서 이상형이 논리적으로 따라나와야 한다.**
힘을 숭상하는 무투파가 신성을 요구하면 앞뒤가 안 맞는다.

> **비용 감각** — 최악의 경우 3장 × 3장 = **9장**. 능력 카드 손패 상한이 10장이므로 이게 상한선이다.
> 같은 능력 2장짜리로만 걸리면 3 × 2 = 6장.

## 대체 경로(alter)는 **다른 종류의 자원**으로 준다

특정 자원을 못 뽑으면 카드가 영구히 잠기는 상황을 막는다.

| 대체 수단 | 성격 |
|---|---|
| **각성 상태** | 한 번 달성하면 유지 — **자원을 소모하지 않는다** |
| **물건 카드** (단서·유물) | 탐색 루트를 탄 플레이어에게 열림 |
| **금화** | 거래·탐색으로 모으는 범용 자원 |
| **빌런 포인트** | 암살 루트를 탄 플레이어에게 열림 (0 요구 = 반대로 깨끗한 플레이) |

> 능력 카드를 능력 카드로 대체하지 않는다. 그러면 우회로가 아니라 가격만 바뀐 같은 길이다.

### 능력 ↔ 각성 대응표

([superpowers/overall.md](superpowers/overall.md) 참고)

| 능력 | 각성 | 비고 |
|---|---|---|
| 매력 | 팜므파탈 | |
| 어둠 | 마리오네트 | |
| 검 | 소드마스터 / **검성**(제노비아) | 둘은 상호 배타 |
| 신성 | 빛의 사제 / **성녀**(이레네) | 둘은 상호 배타 |
| 마법 | 마도사 / **요술사**(미호) | 둘은 상호 배타 |
| 선혈 | 혈술사 / **진조**(바토리) | 둘은 상호 배타 |
| 독약 | **독술사**(마리) | 일반 각성 루트 없음 |
| 금화 | **만물금본**(그레이스) | 금화 5로 일반 각성 택1도 가능 |

## 미결 사항

- [ ] 대체 수단이 **각성에 14종으로 몰려 있다.** 각성은 소모가 없는 상태라
      각성한 플레이어가 지나치게 유리해질 수 있음 — 물건·빌런 포인트로 분산할지 판단 필요
- [ ] 그중 **`팜므파탈` 하나가 6종의 대체**를 담당한다. 매력 5장으로 각성하면
      성향 카드 6종이 한꺼번에 뚫리는 셈이라 특히 강하다
- [ ] **17~20번은 대체 경로가 없다.** "특정 자원을 못 뽑으면 잠긴다"를 막자던 원칙과 어긋나는데,
      조건 자체가 가볍고 다른 축이라 의도된 예외인지 확인 필요

## 카드 상세

> 플레이버는 **남주 본인의 대사**다. 그 한 줄에서 성격과 이상형이 함께 읽혀야 한다.

### 1. 귀족주의

- **이상형**: 매력 1, 검 1, 마법 1 / **또는** `과거의단서` 1장 버림
- **플레이버**: "응당 귀족이라면 만 영지민을 보살펴야하는 법"

### 2. 사디즘

- **이상형**: 매력 1, 독약 1, 선혈 1 / **또는** `팜므파탈` 각성
- **플레이버**: "착하지? 가만있어봐?"

### 3. 츤데레

- **이상형**: 매력 1, 신성 1, 어둠 1 / **또는** `팜므파탈` 각성
- **플레이버**: "착각하지 마. 그냥 지나가는 길이었을 뿐이니까."

### 4. 집착

- **이상형**: 매력 1, 독약 1, 어둠 1 / **또는** `팜므파탈` 각성
- **플레이버**: "어디 갔었지. 내 눈 앞에서 절대 사라지지 말도록."

### 5. 기사도

- **이상형**: 매력 1, 검 1, 신성 1 / **또는** `팜므파탈` 각성
- **플레이버**: "레이디를 위해서라면 기꺼이 칼이 되드리죠."

### 6. 선민주의

- **이상형**: 매력 1, 마법 1, 선혈 1 / **또는** `팜므파탈` 각성 / 미호는 요마변환기를 얻기 전에는 해당 이상형을 충족할 수 없다.
- **플레이버**: "마력이 있다는 건 선택받았다는 뜻이지."

### 7. 물질만능주의

- **이상형**: 금화 2 / **또는** `만물금본`으로 능력 각성
- **플레이버**: "세상 모든 건 값을 메길 수 있다. 사람도 마찬가지고."

### 8. 외모지상주의

- **이상형**: 매력 2 / **또는** `팜므파탈` 각성
- **플레이버**: "보기에 좋은 떡이 먹기도 좋은 법인데."

### 9. 무투파

- **이상형**: 검 2 / **또는** `소드마스터` 또는 `검성` 각성 / `검성`인 플레이어가 `약혼` 액션을 했을 경우 사망하는 경우를 제외하고 어떠한 경우에도(잔느라도) 약혼을 파기할 수 없다.
- **플레이버**: "말은 됐고. 검을 들어."

### 10. 책벌레

- **이상형**: 마법 2 / **또는** `마도사` 또는 `요술사` 각성
- **플레이버**: "빙계마법은사실수계마법보다는시간계마법에더높은연관성이있다는가설에대해서너도동의하지?"

### 11. 독실

- **이상형**: 신성 2 / **또는** `빛의 사제` 또는 `성녀` 각성 / `성녀`인 플레이어가 `약혼` 액션을 했을 경우 사망하는 경우를 제외하고 어떠한 경우에도(잔느라도) 약혼을 파기할 수 없다.
- **플레이버**: "(두 손을 모으며) 빛의 은총이 있길."

### 12. 마조히즘

- **이상형**: 어둠 2 / **또는** `마리오네트` 각성
- **플레이버**: "날 더 옭아매줘. 너의 것으로 만들어줘."

### 13. 광혈도

- **이상형**: 선혈 2 / **또는** `혈술사` 또는 `진조` 각성 / `진조`인 플레이어가 `약혼` 액션을 했을 경우 사망하는 경우를 제외하고 어떠한 경우에도(잔느라도) 약혼을 파기할 수 없다.
- **플레이버**: "오. 뱀파이어 퀸이시여. 부디 응답해주소서."

### 14. 알코홀릭

- **이상형**: 독약 2 / **또는** `독술사` 각성
- **플레이버**: "...히끅! 그 병도 줘봐..."

### 15. 재능주의

- **이상형**: 검 1, 마법 1, 신성 1 / **또는** 아무 각성 상태
- **플레이버**: "허. 천재로군."

### 16. 악성

- **이상형**: 어둠 1, 독약 1, 선혈 1 / **또는** 빌런 포인트 1
- **플레이버**: "악마숭배교가 발호했다고? 이거 흥미롭군."

### 17. 수집가

- **이상형**: 금화를 제외한 물건 1
- **플레이버**: "오. 그 반지 좀 볼 수 있겠나?"

### 18. 노력가

- **이상형**: 아무 각성 상태
- **플레이버**: "재능을 각성하는 건 아무나 하는 일은 아니지."
  
### 19. 상냥함

- **이상형**: 빌런 포인트 0
- **플레이버**: "어디 다친데는 없어?"

### 20. 진심을 준다면

- **이상형**: 약혼 시 두근! 토큰을 1 지불. 잔느가 약혼을 파기할 수 없다.
- **플레이버**: "내가 모든지 해줄게. 잔느? 그게 누구더라?"
