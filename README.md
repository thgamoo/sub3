# 삼류 악녀는 싫어!

> 본격! 한국풍 로판 클리셰 전략 보드게임

로맨스판타지 부문 최고의 베스트셀러 소설 **"판 로만티카의 소녀"** 의 세계로 빙의한 8명의 조연 악녀 중 하나를 골라, 주인공 잔느에게 처단당하는 운명을 거스르고 살아남아 자신만의 결말(엔딩)을 쟁취하는 전략 보드게임입니다.

이 저장소는 게임의 **기획·설정 문서**와 **캐릭터/일러스트 리소스**를 담고 있습니다.

## 게임 개요

- **장르**: 한국풍 로맨스판타지 클리셰 전략 보드게임
- **컨셉**: 트럭에 치여 소설 속 "운명의 조연 악녀"로 빙의 → 다른 빌런들을 처치하고 살아남아 행복(엔딩) 쟁취
- **플레이어**: 8명의 서브 빌런(플레이어 캐릭터) 중 택 1
- **핵심 루프**: 지역을 이동하며 카드를 모으고 → 능력을 각성하고 → 남주를 유혹하거나 경쟁자를 모략하며 → 자신에게 맞는 엔딩 조건을 완성

## 세계관 요약

소설 "판 로만티카의 소녀"를 무대로 한 대륙. 지역마다 세력과 규칙이 다릅니다.

| 지역 | 특징 |
| --- | --- |
| 중부 — 아카데미 | 대륙의 중심, 중앙 마탑. 주인공 잔느의 시작점. **불살령**으로 이곳에선 모략(암살) 불가 |
| 북부 — 프로스트하임 공국 | 설원, 영원의 관. 대공자 지크프리트의 땅 |
| 북동부 — 이제벨의 자유도시 | 겉은 자유도시, 실은 악마숭배자의 소굴 |
| 남부 — 루멘교 왕국연합 | 교회·왕국연합. 조반니의 활동지. 빈사 치료 가능 |
| 동부 — 율리우스 제국 | 황가와 음모의 땅. 동부 바다엔 대해적 |
| 서부 — 무법지대 | 척박한 싸움터, 투기장 |
| 극동 | 대륙 밖. 황제의 증표가 잠든 곳(군림엔딩) |

세계에는 표층 설정 너머 **3층 구조의 진실**이 숨어 있습니다 — ① 고대 SF 문명(반물질유전공학·기계지성 HAL)의 흔적, ② 용사와 승천의 시대, ③ "이 세계는 소설 그 자체"라는 메타 진실. 자세한 내용은 [`docs/world/overall.md`](docs/world/overall.md) 참고.

## 플레이어 캐릭터 (서브 빌런 8인)

| # | 캐릭터 | 시작지점 | 시작자원 | 모티프 |
| --- | --- | --- | --- | --- |
| 1 | 동부의 꽃 — 샬롯 | 중부 | 금화 2, 매력 3 | 조피 샤를로테 공녀 |
| 2 | 어둠의 시녀 — 데이지 | 동부 | 금화 1, 매력 1, 어둠 2 | 데이지 벨 |
| 3 | 부두술사 — 마리 | 서부 | 금화 1, 매력 1, 독 2 | 마리 라보 |
| 4 | 마력없는 마법사 — 미호 | 중부 | 금화 1, 매력 2, 마법 2 | 구미호 |
| 5 | 잊혀진 진조 — 바토리 | 북부 | 매력 2, 선혈 2 | 바토리 에르제베트 |
| 6 | 전처녀 — 제노비아 | 남부 | 금화 1, 검 2 | 제노비아 여왕 |
| 7 | 성녀후보 — 이레네 | 중부 | 신성 2, 매력 1 | 이레네 |
| 8 | 대해적 — 그레이스 | 동부 바다 위 | 금화 3, 매력 2 | 그레이스 오말리 |

각 캐릭터는 소설 원작에서 주인공에게 처단당하는 **"원래 운명"**, 반전이 담긴 **"숨겨진 과거"**, 그리고 이를 밝히는 **"과거의 단서"** 물건 카드를 가집니다. 상세는 [`docs/characters/`](docs/characters/) 참고.

## 진행 방식 (Actions)

플레이어는 자기 차례마다 다음 행동 중 하나를 선택합니다.

1. **이동** — 이웃 지역으로 이동(금화 1 소모)
2. **탐색** — 주사위를 굴려 능력/물건 카드 획득
3. **수행** — 능력 카드 2장(아카데미는 3장) 획득
4. **각성** — 같은 능력 카드 5장으로 고유능력 획득
5. **유혹** — 매력 카드로 남주의 이상형 카드 오픈
6. **모략** — 빌런/남주/플레이어 대상 암살 시도(중부에선 불가)
7. **거래** — 같은 지역의 다른 플레이어와 물건 카드 거래
8. **약혼** — 남주의 이상형을 모두 오픈했다면 약혼 시도

상태이상(빈사·현상수배·여론악화)과 해제 방법은 [`docs/rules/actions.md`](docs/rules/actions.md) 참고.

## 각성과 고유능력

같은 종류의 능력 카드를 모아 **각성**하면 **고유능력**을 얻습니다.

- **일반 고유능력 6종**: 팜프파탈(매력)·마리오네트(어둠)·소드마스터(검)·빛의 사제(신성)·마도사(마법)·진조(선혈)
- **특수 고유능력**: 미호(요술사)·제노비아(검성)·이레네(성녀)·바토리(뱀파이어 퀸)·그레이스(만물금본)·마리(독술사) — 특정 캐릭터만 각성 가능하며, 일반 능력과 상호 배타적

상세는 [`docs/superpowers/overall.md`](docs/superpowers/overall.md) 참고.

## 엔딩 (승리 조건)

| 엔딩 | 조건 요약 |
| --- | --- |
| 노멀엔딩 — "나는 살아있다" | 최후의 1인 생존 + 각성 + 모든 빌런 처치 |
| 해피엔딩 — "저 오늘 결혼해요" | 생존 + 각성 + 남주와 결혼 + 해당 남주 통치권 빌런 제거 |
| 군림엔딩 — "짐의 발 앞에 조아리거라" | 생존 + 각성 + 과거 단서 3개↑ + 극동의 황제 증표 + 황제 선언 |
| 승천엔딩 — "본녀는 세계의 진실을 깨달았도다" | 각성 + 세계 진실 물건 4종↑ + 아카데미에서 승천의 문 소환 |
| 멸망엔딩 — "내가 가질 수 없다면 부숴버릴거야" | 전원 사망 시, 빌런 포인트 최다 획득자 승리 |

상세는 [`docs/endings/`](docs/endings/) 참고.

## 카드 구성 (요약)

- **능력 카드** — 검/매력/마법/선혈/신성/독약/어둠, 총 100장 (매력 40장 + 나머지 각 10장)
- **물건 카드** — 캐릭터 과거의 단서 27장 + 세계 진실 물건 10장 + 엘릭서 3장 = 총 40장
- **금화 카드** — 총 25장 (이동·거래에 사용)

상세는 [`docs/rules/tokens.md`](docs/rules/tokens.md) 참고.
